# Local overview

The `nextmv.local` package provides functionality to run Nextmv Applications
locally on your machine.

!!! success "Free to use"

    The `local` experience is completely free of charge and does not require a
    Nextmv account.

At Nextmv, we believe that decision models should be easy to build, test, and
run. The Nextmv [Cloud Platform][cloud-overview] provides great functionality
to manage and run your decision models. However, we understand that you may not
be ready to move to Cloud just yet, or you are simply looking to explore Nextmv
to see how it can help you build better decision models.

We have created the local experience to help you get started with Nextmv, as a
sort of "community edition" of the Nextmv Platform. The local experience
provides a great way to get familiar with Nextmv, and it is a great tool to
build and test your decision models before moving to Cloud.

In this section you will find the following tutorials encompassing the main
features of the local experience:

| Feature | Description |
|---------|-------------|
| [Get started - new app][get-started-new-app] | Create a new Nextmv Application and run it locally |
| [Get started - existing app][get-started-existing-app] | Run your existing Python decision model locally |
| [Run an app][runs] | Create and manage runs for your local Application |
| [Sync to Cloud][sync] | Push your local Application to Nextmv Cloud |
| [Visualize run assets][visuals] | View the visual assets produced by your local runs |
